# Architecture changelog

## 2026-08-06 — Public event discovery and privacy-safe map

- Реальные опубликованные события заменяют демонстрационные данные карты и
  списка; фильтров даты и категории в MVP нет.
- Для скрытых мест сохраняется отдельная OSM-опорная точка улицы. Публичная
  проекция группирует события по ней и никогда не использует точку события.
- Добавлены безопасные публичные карточки события и организатора, постоянная
  ссылка `/event/{id}` и персональная проверка права на точный адрес.

## 2026-08-06 — Published event management foundation

- Добавлены неизменяемые заявки на изменение опубликованного события,
  идемпотентность, одна применённая смена времени и немедленная отмена.
- Одобрение изменения атомарно переключает публичную версию и создаёт
  уведомления участникам; отказ сохраняет прежнюю версию.
- Celery Beat раз в минуту завершает истёкшие обычные и «Особые» события.

Краткая история принятых решений. Детальные предыдущие формулировки доступны в
Git history. Даты указаны в часовом поясе Europe/Moscow.

## 2026-08-05 — реализована отправка обычного события

- Создание разделено на четыре клиентских шага без сохраняемого черновика.
- Полный submit атомарно создаёт событие, первую revision, фотографию и при
  необходимости запись проверки; повтор запроса защищён idempotency key.
- Доверенные организаторы публикуют сразу минимум за час до начала, новые
  отправляют событие на проверку минимум за шесть часов.
- Сервер повторно проверяет категорию, городскую границу, адрес, расписание,
  capacity и принадлежность безопасно обработанной фотографии.

## 2026-08-05 — реализована основа отдельной staff-панели

- Добавлены отдельные staff-аккаунты, Argon2id credentials, серверные сессии,
  постоянный login throttle, permissions и неизменяемый административный аудит.
- Первый администратор атомарно создаётся один раз из `ADMIN_LOGIN` и
  `ADMIN_PASSWORD`; последующие запуски не меняют сохранённые данные.
- `admin.podvval.xyz` переведён с закрытой `404` на отдельный desktop-first
  интерфейс со счётчиками и безопасной историей действий.
- Staff-вход изолирован от Telegram-сессий и ограничен точным admin host/origin,
  отдельной host-only cookie, CSRF, 8-часовым сроком и 30 минутами бездействия.

## 2026-08-04 — принят Stage A и уточнён состав MVP

- Пользовательский вход в MVP оставлен только в Telegram Mini App; website OIDC
  и пользовательские действия обычного сайта перенесены за рамки MVP.
- Обновлены категории, ограничения категории «Работа» и отдельный тип
  `Особое`: admin-only, без публичного организатора, участия, чата, attendance,
  оценок и reputation; низкая активность его не скрывает.
- Лимит изменения даты/начала/окончания снижен с двух раз до одного; заданный
  capacity начинается с трёх; добровольный выход сразу отзывает доступ к чату.
- Доверие организатора связано с тремя завершёнными неотменёнными событиями,
  каждое минимум с тремя подтверждёнными кодом посещениями.
- Принят `ADR-022`: локально только правки/Git, проверки на VPS, адреса `/`,
  `/app`, `/api`, `admin.podvval.xyz`, необязательный Telegram proxy и внешний
  HTTPS-контур после зелёного G6.
- Полный G6 пройден на VPS на опубликованном commit
  `940f0281405a00cf83335367f465840bf042ab2e`: 58 тестов, coverage 91.52%,
  миграции и runtime smoke успешны, Critical/High уязвимости и утечки секретов
  не обнаружены. Commit перенесён fast-forward в `main`; отдельный evidence
  commit должен пройти повторный gate.

## 2026-08-01 — принят UI/UX-контракт и синхронизированы продуктовые правила

- Создан единый UI-документ для сайта, Mini App и admin-панели с разделами
  MVP/Post-MVP, навигацией, ключевыми экранами, состояниями и accessibility.
- Принят `PD-020`: LookingPost Q&A, safe anonymous preview, новые text limits,
  report-based moderation и связанные уведомления.
- Persistent Event drafts удалены из активного G4/G5/retention: форма живёт
  только в открытом клиенте, а сервер принимает полный финальный submit.
- Deep links закреплены как ссылки на object/action без передачи permission;
  Telegram write access не запрашивается.
- Код, макеты, ветки и commits этим изменением не создавались.

## 2026-07-30 — документация сокращена без изменения решений

- 22 принятых документа G4 объединены в семь тематических файлов.
- Повторные checklists, traceability, текстовые копии диаграмм, исследования
  уже сделанного выбора и подробный исторический журнал удалены.
- Сохранены PD, все ADR, требования, guards, transitions, privacy/auth,

- Отдельные Mermaid-файлы оставлены только для существенно полезных связей.
- Продукт, API, данные, код и статус G6 не изменились.

## Ключевые решения

| Область | Принято |
|---|---|
| Продукт | бесплатные безопасные офлайн-события; три launch city; возраст 14+ |
| Доступ | public read-only web без user login; Mini App initData для действий |
| Identity | единый internal user; staff identity отдельно от Telegram |
| Архитектура | модульный монолит, семь owner-модулей и отдельные schemas |
| Данные | PostgreSQL/PostGIS truth, immutable revisions, compact final snapshots |
| Интерфейс | mobile map-first, desktop list/map/panel, shared UI contract без готовой design system |
| Async | transactional outbox, Celery/Redis, Kafka только по triggers |
| Карта | MapLibre + OpenFreeMap + закрытый regional Nominatim |
| Приватность | street/exact projections, fail-closed hide и минимизация telemetry |
| Media | безопасный re-encode без EXIF, local protected storage |
| Reputation | ledger/projections, private production policy, trust_safety блокирует |
| Operations | Stage 1 Compose, off-server backup позднее, ручной deployment |
| Quality | coverage ≥75%, security gates и authoritative clean-VPS verification |
